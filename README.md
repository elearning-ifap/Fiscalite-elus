# La fiscalité en Nouvelle-Calédonie — module élus du Congrès

Version **V7.2.27 · noyau v1.8.1** — 28 octobre 2026 — IFAP × Congrès de la Nouvelle-Calédonie.

Version web (aperçu Netlify / GitHub Pages) du module SCORM. Le package déposé dans LIANE (Moodle) est fourni séparément.

## Structure

```
index.html        module complet (HTML/CSS/JS, sans dépendance externe)
media/            budgets 2026 (reversement, répartition) + media/experts/ (17 visuels experts)
images/           carte des terres coutumières
.nojekyll         désactive Jekyll sur GitHub Pages
```

Les chemins sont relatifs : conserver `media/` et `images/` à côté de `index.html`.
Hors LMS, le module fonctionne en mode prévisualisation (aucune donnée SCORM enregistrée).
